DELAY

O delay é gravado junto com o preset. Mix em 0% deixa o delay desligado.

EFEITOS

Os efeitos valem para todos os presets e ficam salvos neste aparelho. Cadeia: Efeito 1 → Efeito 2 → Delay → Reverb. Chorus, phaser e reverb deixam o grave seco (abaixo de ~150 Hz) para o baixo não perder definição.

AVANÇADO

Modulação, ondas, osciladores e teclado são gravados no preset. Afinação, faixa das rodas, curva de toque, MIDI e entrada externa valem para todo o AURA neste aparelho. Com a entrada externa, use fones para evitar microfonia. Para ouvir só o sinal externo, zere o volume dos osciladores.

ARPEJADOR

Segure as teclas para o arpejador tocar as notas em sequência. Os ajustes valem para todos os presets. Dá para ligar e desligar pelo botão do controlador (Mapear knobs e botões).
